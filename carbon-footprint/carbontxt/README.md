# carbon.txt usage in Wagtail ecosystem

## carbon.txt check

Checking for [carbon.txt](https://carbontxt.org/) presence and content via the [carbon.txt validator](https://github.com/thegreenwebfoundation/carbon-txt-validator).

## Green Web check

The Green Web Foundation’s [Green Web Check](https://www.thegreenwebfoundation.org/green-web-check), via the [check_greenweb.py](./check_greenweb.py) script.

Results for 6431 sites tested:

- 2576 (40%) are reported as green hosting
- 2811 (43%) are reported as not green hosting
- 1046 (16%) report errors
